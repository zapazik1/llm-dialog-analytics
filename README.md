# Аналитика диалогов ИИ-агента

Инструменты, которыми я проверяю, как работает агент в продакшене: метрики по выгрузке диалогов и разметка диалогов через LLM. Отвечают на вопросы заказчика «сколько обращений агент закрывает сам» и «где он теряет клиентов», без чтения сотен переписок вручную.

Выгрузка в формате платформы NextBot. Имена клиентов при чтении отбрасываются. В репозитории только синтетические данные.

## Что считается

**По сообщениям** (`analytics/metrics.py`):

- диалоги в день, где клиент написал хотя бы раз, и сообщения клиентов, агента и оператора;
- исходы вызовов функции по полю `status` в ответе: сколько записей создано, сколько раз время оказалось занято, сколько ошибок;
- доля диалогов с участием оператора и доля начатых ночью.

**Через LLM** (`analytics/llm_label.py`): каждый диалог получает категорию.

| Категория | Смысл |
| --- | --- |
| A | агент закрыл запрос сам или дал верный следующий шаг |
| B | реальная ошибка или ограничение агента |
| C | не оценивается: рассылки, напоминания, спам, пустые диалоги |

Уровень автоматизации считается как A / (A + B). Шум из категории C в знаменатель не входит: в полной выгрузке его бывает больше половины, и без очистки метрика врёт в любую сторону.

## Результаты на рабочих проектах

Цифры обезличены.

| Проект | Период | Результат |
| --- | --- | --- |
| Медицинская клиника, запись к врачам | 6 дней | в среднем 110 диалогов в день; 186 записей в 159 диалогах; 12 раз выбранный слот оказался занят |
| Сеть шинных центров, подбор и запись | 4 месяца | 2 482 диалога; 19,3% закрыты без менеджера; 16,6% начаты ночью; 471 целевое действие (запись на визит или доставка), конверсия в целевое действие 15,5% |
| Студия эпиляции, запись и перенос | 1 выгрузка | из 311 диалогов оценивались 85; агент закрыл сам 70 (82,4%), разметка через LLM |
| Подбор автомобиля, квалификация лида | 1 выгрузка | из 98 диалогов с ответом агента 72 дошли до заявки (73,5%); 24 из 26 потерь на первом вопросе о модели, это прямое указание, что менять в сценарии |

Диалоги, где агент не ответил ни разу или был поставлен на паузу, в квалификацию не включались и считались отдельно.

## Запуск

```bash
pip install -r requirements-dev.txt
python sample/make_sample_export.py
python -m analytics sample/sample_export.xlsx --from 2099-06-01 --to 2099-06-06 --booking save_appointment_details
pytest
```

Пример отчёта на синтетической выгрузке:

```
| День       | Диалогов | Сообщений клиентов | Ответов агента | Сообщений оператора |
| 2099-06-01 |       47 |                 72 |             72 |                   1 |
...
Диалогов в день в среднем: 61.
Функция save_appointment_details: {'success': 181, 'error': 11, 'busy': 37}
```

LLM-разметка подключается функцией `openai_complete(api_key)` или любой другой, которая принимает промпт и возвращает JSON.

## Структура

```
analytics/export.py     чтение выгрузки без персональных данных
analytics/metrics.py    активность по дням, исходы функций, оператор и ночь, текст для разметки
analytics/llm_label.py  промпт и разбор ответа модели, уровень автоматизации
analytics/__main__.py   отчёт в Markdown
sample/                 генератор синтетической выгрузки
```
